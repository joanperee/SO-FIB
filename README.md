# Sistemes Operatius (SO) - FIB UPC

Aquest repositori conté tot el material pràctic, exercicis i codi font de l'assignatura de Sistemes Operatius (SO) impartida a la FIB - UPC. 

## 📂 Estructura del Repositori

El repositori es divideix en dos directoris principals. He pujat els **fitxers font (.c)** i els corresponents **compilats** perque es puguin provar directament:

### `exercicis_lab/`
Aquesta carpeta està dedicada a la preparació i resolució d'exercicis:
* **Parcials i finals:** Resolució d'exercicis d'exàmens d'anys anteriors.
* **Acadèmia:** Exercicis de reforç i pràctica addicional centrats específicament en **processos bàsics** i el **sistema de fitxers**.

### `practiques/`
Conté el codi font i les respostes de les sessions de laboratori de l'assignatura, així com exercicis relacionats amb el seguiment de la teoria. Les pràctiques incloses són:
* **S2 - El lenguaje C:** Creació d'executables, `Makefiles`, punters i estructuració de codi
* **S3 - Procesos:** Creació i gestió de processos concurrents i seqüencials (ús de `fork`, `execlp`, `waitpid`)
* **S4 - Comunicación de procesos:** Gestió i tractament d'esdeveniments i senyals (`sigaction`, `kill`, `alarm`)
* **S5 - Gestión de Memoria:** Relació de codi i espai lògic, reserva dinàmica i anàlisi de zones de memòria (`sbrk`, `malloc`, `/proc`)
* **S6 - Análisis de rendimiento:** Estudi de l'impacte de la càrrega del sistema, prioritats i polítiques de planificació (`top`, `nice`, `vmstat`)
* **S7 i S8 - Gestión de Entrada/Salida:** Redireccions, independència de dispositius, comunicació mitjançant canonades (pipes amb i sense nom) i *sockets* locals
* **S9 - Sistema de Ficheros:** Ús de crides al sistema per treballar amb Inodes, *hard links*, *soft links* i el punter de lectura/escriptura (`lseek`, `stat`, `mknod`)
* **Seguiment teoria:** Pràctiques i problemes vinculats directament amb el temari de teoria.
